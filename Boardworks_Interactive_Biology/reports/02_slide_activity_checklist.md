## Control legend (all four files)

| Control | Action |
|---|---|
| Purple ▶ / ◀ | Next / previous **visible** slide |
| Green teaching buttons | Jump (contents, reveal, correct) |
| Orange Reset | Return to the first screen of that activity |
| Check / Show all | Open the answer-key slide (hidden) |
| Try again | Return to the question |
| Continue | Next teaching slide |
| Space / click empty area | Next **visible** slide (skips hidden feedback) |
