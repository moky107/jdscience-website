23.
Noah carries out a T-Level occupational task on planning and reviewing laboratory investigations. This is a typical NCFE required-practical style question.
(a) [2 marks]
  • Independent: the factor being investigated
  • Dependent: the measured result or quality check
(b) [2 marks]
  • follow the SOP and keep other variables constant
  • so the test is fair / only one variable is changed
(c) [2 marks]
  • not recording the batch/lot number or operator ID
24.
Noah carries out writing or following an SOP for planning and reviewing laboratory investigations. This is a typical NCFE required-practical style question.
(a) [2 marks]
  • Independent: a step in the method
  • Dependent: whether the acceptance criteria are met
(b) [2 marks]
  • same calibrated instrument
  • so the test is fair / only one variable is changed
(c) [2 marks]
  • skipping a verification check
25.
Noah carries out a COSHH / risk-assessment review for planning and reviewing laboratory investigations. This is a typical NCFE required-practical style question.
(a) [2 marks]
  • Independent: hazard
  • Dependent: control measure effectiveness
(b) [2 marks]
  • same PPE and waste route
  • so the test is fair / only one variable is changed
(c) [2 marks]
  • using expired reagents or the wrong waste stream

  • so the test is fair / only one variable is changed
