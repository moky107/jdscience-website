T-Level Laboratory Sciences
Answer sheet

Data collection, analysis and errors

Separate mark scheme — do not issue with the student worksheet
Time guide: — · Questions: 32 · Total marks: 104
Written in occupational specialism style. Plan techniques, follow SOPs and review data quality.

Indicative marking points. Award marks for equivalent scientific or mathematical wording. Do not issue this sheet with the student worksheet.

1.
State what is meant by a random error.
[1 mark]
  • varies unpredictably
2.
State what is meant by a systematic error.
[1 mark]
  • shifts all results the same way
3.
State what is meant by a transcription error.
[1 mark]
  • wrong number copied into LIMS
4.
State what is meant by an instrument fault.
[1 mark]
  • drift, blockage, lamp failure
5.
State what is meant by sample mix-up.
[1 mark]
  • wrong ID or swapped tubes
6.
State what is meant by Westgard rules (idea).
[1 mark]
  • QC rules that detect error
7.
State what is meant by a control chart.
[1 mark]
  • plots QC over time
8.
State what is meant by root-cause analysis.
[1 mark]
  • 5 whys / fishbone
9.
State what is meant by data integrity ALCOA.
[1 mark]
  • attributable, legible, contemporaneous, original, accurate
10.
State what is meant by process improvement.
[1 mark]
  • change the SOP, training or equipment

  • Dependent: the measured result or quality check

  • follow the SOP and keep other variables constant
  • so the test is fair / only one variable is changed

  • Dependent: whether the acceptance criteria are met
(b) [2 marks]
  • same calibrated instrument
  • so the test is fair / only one variable is changed
(c) [2 marks]
