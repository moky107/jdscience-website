GCSE Chemistry Resources

GCSE Chemistry revision notes, worksheets, past papers and exam practice from the existing JD Science resource library.

This GCSE Chemistry page gathers revision notes, original worksheets and exam practice in one place, then opens the same JD Science resource library used on the past papers screen. Students can move from topic notes to exam-style questions without hunting through a generic file list. IGCSE Chemistry learners following a similar specification will also find useful practice here. Official past papers and mark schemes are linked by exam board, including AQA, Edexcel and OCR, with Eduqas and WJEC available where those routes apply. Each section below keeps the existing resource categories: specifications, worksheets, past questions, examiner reports and videos. Use the board links to open the live resource browser already filtered for GCSE Chemistry, then continue switching type or board there. If you want tutoring on atomic structure, quantitative chemistry or organic topics, Joseph Danso’s science profile explains how 1-to-1 support works.
